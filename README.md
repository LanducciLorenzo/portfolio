# Portfolio – Lorenzo Landucci

MSc Clinical and Health Psychology (Florence) · BSc Economics (Pisa)

Projects on memory, decision making, cooperation and the economics of critical raw materials, combining experimental psychology, behavioural economics and trade data.

| Project | What it shows |
|---|---|
| [`thesis_reanalysis/`](thesis_reanalysis/) | Reproducible Python reanalysis of my MSc thesis on false memories (DRM paradigm, N = 130): mixed ANOVAs validated against independent computations, extended with signal detection theory. |
| [`critical_raw_materials/`](critical_raw_materials/) | Data extension of my BSc Economics thesis: concentration of EU imports of lithium, rare earths, cobalt, graphite and permanent magnets (Eurostat, 2010-2025), China's share, and a scenario of more supply from Australia under the EU-Australia FTA. The data are reconciled with Eurostat's own totals and every result is recomputed independently. |
| [`otree_experiments/`](otree_experiments/) | Two online experiments in oTree: a public goods game on endowment inequality and cooperation (2×2 design), and an online DRM false-memory experiment with three presentation modalities, plus analysis scripts. |

Each folder has its own README with instructions and tests (Italian versions in `LEGGIMI.md`).

Built with the help of AI coding tools, which I use to learn Python and oTree; the research questions, design choices and interpretation are my own.
