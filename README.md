# Portfolio – Lorenzo Landucci

MSc Clinical and Health Psychology (Florence) · BSc Economics (Pisa)

Download `portfolio_lorenzo.zip` (click the file, then "Raw") to see the code.

| Project | What it shows |
|---|---|
| `otree_experiments/` | Two online experiments in oTree: a public goods game on endowment inequality and cooperation (2×2 design), and an online DRM false-memory experiment, plus analysis scripts. |
| `thesis_reanalysis/` | Reproducible Python reanalysis of my MSc thesis on false memories (DRM paradigm, N = 130), extended with signal detection theory. |
| `critical_raw_materials/` | Extension of my BSc Economics thesis: concentration of EU imports of critical raw materials (Eurostat, 2010–2025) and an EU–Australia supply scenario. |

Built with the help of AI coding tools, which I use to learn Python and oTree; the research questions, design choices and interpretation are my own.
